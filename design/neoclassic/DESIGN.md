# DESIGN.md — Neoclassicism / 新古典主义

> 版本 1.2.1 · 2026-11
> 适用：设计师 / 工作室作品集、品牌官网、展览与出版物邀请页、文化机构、移动端 H5，以及聊天等阅读为主的应用界面
> 字体：Cormorant Garamond（标题）/ Inter（正文与标签）
> 使用方式：先选界面类型，再读 §2 共用规则和对应章节；交付前按 §13 验收。
> 展示页视觉基准：`../../style-probe-2.html#n1`。
> 聊天视觉基准：[书页背景对比](./chat-background.html)中的「书页留白」。切换「纯色」可验证装饰不改变布局；切换器与静态示例内容都不是应用需求。

---

## 1. 定位

用对称、留白和高对比衬线建立“庄重感”。整页只有象牙纸色、墨色和一点旧金，所有装饰都必须有结构上的理由（框、线、印章、罗马数字），不是贴上去的花纹。

- **它相信**：秩序让人安静；比例比装饰重要。
- **它拒绝**：亮金渐变、浮雕阴影、卷草花纹、婚礼请柬式的堆砌。

| 适合 | 不适合 |
|---|---|
| 设计师 / 工作室作品集 | 游戏、儿童、潮流快消 |
| 品牌官网、机构介绍 | 高密度后台 |
| 展览 / 出版物 / 邀请页 | 促销、直播、强转化落地页 |
| 建筑、法律、咨询 | 需要强角色感的营销页 |
| 文化项目 H5 | 大量插画 / 3D 的页面 |

| 界面类型 | 优先读取 | 不要套用 |
|---|---|---|
| 展示页 | §5 展示页布局、§6 首屏与展示组件、§7 入场动效 | 不把聊天专用控件当成全站按钮样式。 |
| 聊天应用 | §5 聊天布局、§6 圆角纸面、§8 书页留白、§12 聊天 prompt | 不套首屏对称布局、全视口双线框、罗马编号或入场动效。 |

## 2. Hard rules（不可协商）

1. 页面外框、表格和展示卡片默认圆角 `0`。仅在有明确组件规范时给操作控件加圆角，例如 §6 的消息输入区及其按钮；不要把例外扩散到整页。`box-shadow: none`。
2. 结构线用 `1px` 实线 `--line`，装饰线用 `--gold`。控件边线和焦点环按组件规范，不当作装饰线。
3. 展示页的外框与首屏居中对称。应用界面保留任务所需的侧栏、阅读列与工具区布局，正文和输入内容按阅读方向对齐，不强行居中。
4. 一屏最多 1 处装饰性旧金强调，面积 ≤ 5%；小字金用 `--gold-ink`。聊天中，淡金藏书票是唯一的背景旧金装饰，页边角线用 `--line`；品牌徽记和焦点标记不算背景装饰。
5. 禁止：渐变、玻璃、发光、阴影、卷草花纹、emoji。
6. 标题最多 2 行，用 `text-wrap: balance`；中文标题字距 `-0.01em` ~ `0.005em`。
7. 英文小标题全大写 + `0.14em` 字距；中文不做全大写。
8. 展示性动效 ≥ 400ms，只允许淡入、轻微上移、线条展开；不要弹跳、不要视差。控件反馈不受此下限约束；焦点即时显示。
9. 触控目标 ≥ 44×44；焦点环 2px 实线 + 2px offset。
10. 展示页一屏最多 1 张装饰图；聊天背景不放图。用户上传的附件、消息中的图片等内容不受这条装饰规则限制。

冲突时优先级：**可访问性 > 品牌与内容 > 本文件 > 个人偏好**。

## 3. 色彩

### Light（默认）

| Token | 值 | 用途 |
|---|---|---|
| `--paper` | `#F4EFE4` | 展示页底色、聊天主区及消息阅读列 |
| `--surface` | `#FBF7EE` | 展示页浅色表面、聊天侧栏及不透明输入框 |
| `--ink` | `#1C1A17` | 标题、正文、深色线 |
| `--muted` | `#5C5448` | 次级正文、说明 |
| `--line` | `#D8D0BF` | 1px 分隔线、外框 |
| `--gold` | `#9A7B4F` | 装饰线、菱形、印章；**不用于小字** |
| `--gold-ink` | `#7A5C34` | 小号金色文字（9–14px） |

### Dark

| Token | 值 |
|---|---|
| `--paper` | `#161411` |
| `--surface` | `#1D1A16` |
| `--ink` | `#EFE8DA` |
| `--muted` | `#A79C8A` |
| `--line` | `#332E27` |
| `--gold` | `#C2A36B` |
| `--gold-ink` | `#D8BC8A` |

### 展示页用量（近似）

- 85% 纸色
- 10% 墨色文字与线
- 5% 旧金（线、印章、编号）

### 对比度（实测）

| 组合 | 比值 | 可用性 |
|---|---|---|
| ink / paper | 15.2:1 | 正文、标题 |
| muted / paper | 6.5:1 | 正文、说明 |
| gold-ink / paper | 5.3:1 | 小字标签 |
| gold / paper | 3.4:1 | 仅 ≥24px 或非文本装饰 |
| line / paper | 1.3:1 | 仅装饰 |

### 规则

- 金色分两档：`--gold` 做线，`--gold-ink` 做字。不要用 `--gold` 写 10px 标签。
- 深色模式不是反色：纸色变暖黑，金色提亮；不要用纯黑 `#000`。
- 需要强调时优先用字重和字号，不要增加第二种颜色。

## 4. 字体

### 角色

| 角色 | 字体 | 字重 | 说明 |
|---|---|---|---|
| Display | Cormorant Garamond | 400–500 | 中文回退 Songti SC / 思源宋体 |
| Small caps | Cormorant Garamond | 400 | 英文副标题，大写 + `0.14em` |
| Body | Inter | 400 | 中文回退 PingFang SC |
| Label | JetBrains Mono | 400–500 | 9–10px 大写 + `0.3em` |
| Roman | Cormorant Garamond italic | 400 | 罗马数字、编号 |

Cormorant 的高对比笔画是这套系统的核心；不要用它排正文（小字号会断笔）。

### 字阶

| Token | size / line-height / tracking | 用途 |
|---|---|---|
| `display` | `clamp(44px, 7.2vw, 104px)` / 1.04 / `0.005em` | H1，最多 2 行 |
| `display-en` | `0.42em` / 1.2 / `0.14em`，大写 | 英文副标题 |
| `h2` | `clamp(28px, 4vw, 44px)` / 1.1 / `0.005em` | 区块标题 |
| `body` | `14px` / 1.75 / `0.02em` | 正文 |
| `small` | `11px` / 1.6 / `0.04em` | 注释、页脚 |
| `label` | `9.5px` / 1 / `0.3em`，大写 | 导航、eyebrow |
| `roman` | `13px` / 1 / `0.1em`，斜体 | 罗马数字 |

中文正文行长 **28–34 字**；英文 55–70 字符。

### 中文规则

- 中文标题用 Songti SC **500**，不要 700；宋体加粗会糊。
- 中文不做 `text-transform`；不单独加宽字距（超过 `0.02em` 会散）。
- 行高：标题 1.04–1.1；正文 1.75。
- 中文标点用全角；数字与单位不空格（`2026`、`240ms`）。

## 5. 布局

### 展示页结构

- 居中容器：max-width `1240px`，页边距 ≥1080 用 `72px`，760–1080 用 `32px`，<760 用 `24px`
- 外框：距视口 `58px 16px 16px`，`1px` 实线；内框再内缩 `5px`，用 `--gold` 35% 透明度
- 首屏高度 `100svh - 46px`（46px 为顶部标签条）；内容垂直居中

### 间距

`4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96 / 128`

- 首屏上下：48–64
- 标题 → 英文副标题：10
- 副标题 → 分隔饰线：24
- 饰线 → 正文：24
- 正文 → 链接：26

### 形状

- 结构性边框 radius 0；交互控件圆角按 §6 组件定义
- border `1px`
- shadow none
- 允许的装饰：双线框、菱形饰线、圆形印章、罗马数字

### 展示页响应式

| 断点 | 行为 |
|---|---|
| ≥1080 | 双线框 + 三栏服务；标题 104px |
| 760–1079 | 保持居中；标题降级；三栏保持 |
| 620–759 | 服务改单列，用横线分隔；印章隐藏 |
| <620 | 外框 inset 8px；导航只留居中 wordmark；标题 clamp 最小 38px |

移动端：框架仍保留（这是风格的一部分），但缩到 8px；不要隐藏正文。

### 聊天布局

- 现有应用保留侧栏宽度、会话顶栏、消息滚动区和输入区定位。消息阅读列可在主区居中，但中文正文、表格、输入内容仍左对齐。
- 输入框外边缘和消息阅读列共用同一个内容宽度与对齐基准。新建且没有布局约定时，可参考样板：侧栏 `248px`、阅读列最大 `760px`、主区两侧各至少 `16px`。这些不是强制覆盖现有布局的尺寸。
- 宽表格、长链接和代码块在各自容器内换行或滚动，不撑宽页面。窄屏沿用应用已有的侧栏折叠或抽屉逻辑，不因装饰新增断点或隐藏导航功能。
- 先放内容和操作，再利用剩余的侧栏空白与正文右边距放装饰。关闭装饰时，正文、输入框、导航和底部工具的位置与尺寸保持不变。

## 6. 组件

### 导航

三栏对称：左 `Atelier`、中 wordmark、右 `Shanghai`；9px 大写 + `0.3em`；底部 1px 线。

```html
<header class="grid grid-cols-[1fr_auto_1fr] items-center border-b border-line py-5
               font-mono text-[9px] uppercase tracking-[0.3em] text-muted">
  <span>Atelier</span>
  <span class="justify-self-center text-[11px] tracking-[0.34em] text-ink">Studio Null</span>
  <span class="justify-self-end">Shanghai</span>
</header>
```

### 首屏

- eyebrow：`MMXXVI — 独立设计工作室`，9.5px，`--gold-ink`，`0.34em`
- H1 居中，2 行；英文副标题在下一行，字距 `0.14em`
- 饰线：`64px 线 + 5px 旋转方块 + 64px 线`
- 正文：max-width 40ch，居中
- 链接：文字 + 1px 下划线，高 44px

### 链接与主操作

- 正文中的跳转（如看作品、阅读详情）用文字链接 + 下划线，不做填充按钮。聊天侧栏导航保留原有当前项样式，不强制每行加下划线。展示页短 CTA 的英文标签可用 9.5px 大写 + `0.24em`，下划线偏移 5px。
- 链接 hover：下划线和文字变 `--gold-ink`，250ms。
- 发送、提交等执行命令的主操作用语义化 `<button>`，可用 `--ink` 填充、`--surface` 作为前景；不把跳转链接的样式套给表单主操作。

### 消息输入区（圆角纸面）

用于聊天、助理等已有阅读列的页面。保持原布局和输入区宽度，不为它重排整页，也不移植展示页的双线框、印章或罗马编号。

| 部件 | 默认规范 | 状态 |
|---|---|---|
| 外框 | 一层纸面容器：背景 `--surface`、`16px` 圆角、`1px` 实线、内边距 `7px`。浅色边线 `#B6AA96`，深色边线 `#6B6153`；无阴影、无双线框。 | 有子控件聚焦时边线变 `--gold-ink`；键盘焦点仍显示在实际聚焦的控件上。 |
| 输入区 | 无内层边框或独立底色。正文无衬线 `16px / 24px`，按阅读方向对齐；占位文案用 `--muted`，不能代替可访问名称。 | 单行起步，多行向上增长至约 `100px`，超出后内部滚动；操作按钮固定在底部对齐。 |
| 添加附件 | `Paperclip` 线性图标；`44 × 44px` 圆形点击区；默认透明、图标 `--muted`，无描边。 | hover 才显示暖纸色圆底，浅色 `#ECE4D5`、深色 `#302820`，图标用 `--ink`。可访问名称「添加附件」；选中文件后显示文件名，支持移除。 |
| 发送 | `ArrowUp` 线性图标；`44 × 44px` 正圆；可发送时 `--ink` 圆底、`--surface` 箭头。 | 无可发送内容时用原生 `disabled`；浅色底 `#E7DECF` / 箭头 `#645A4A`，深色底 `#302820` / 箭头 `--muted`。可访问名称「发送消息」。状态切换不改变尺寸，不缩放、不位移。 |

- 单行从左到右为输入区、附件、发送，列间距 `4px`。窄屏保留 `44 × 44px` 按钮，输入列可收窄、文字可换行；不要靠缩小按钮消除溢出。
- 同一工具栏图标选同一套线性图标（例如 Lucide），统一 `19 × 19px`、`1.75px` 线宽、圆端点，不与实心图标混用。图标由按钮提供可访问名称，图标自身设为装饰。
- 键盘聚焦用 `2px` 实线 `--gold-ink` 焦点环 + `2px` 偏移，不裁掉焦点环。发送是否可用由现有业务逻辑决定；纯空白不能触发发送，附件是否允许单独发送沿用产品规则。保留应用既有的发送、换行和附件行为；中文输入法组词时不得误触发发送。
- 反例：直角外框 + 方形发送按钮；整条输入区做成胶囊；默认给附件和发送同等深色底；输入区内外各画一层边框。

### 罗马数字栏目

三栏，居中，`I / II / III` 用 Cormorant italic + `--gold-ink`；标题 10.5px 大写；说明 11px。

```html
<div class="grid grid-cols-3 border-t border-line pt-5 text-center">
  <div class="px-4">
    <b class="font-serif text-[13px] italic text-gold-ink">I</b>
    <h3 class="mt-2.5 font-mono text-[10.5px] uppercase tracking-[0.22em]">品牌</h3>
    <p class="mt-1.5 text-[11px] text-muted">命名 · 标识 · 视觉系统</p>
  </div>
  <!-- II / III 同理，+ div 用 border-l 分隔 -->
</div>
```

### 印章

- 双圆环 + 环绕文字 + 中心字母；`64–88px`；旋转 `-8°`；`--gold`
- 只在 ≥620px 显示；不要做多个印章

```html
<svg viewBox="0 0 100 100" class="h-20 w-20 text-gold" aria-hidden="true">
  <defs><path id="seal" d="M50,50 m-37,0 a37,37 0 1,1 74,0 a37,37 0 1,1 -74,0"/></defs>
  <circle cx="50" cy="50" r="47" fill="none" stroke="currentColor"/>
  <circle cx="50" cy="50" r="43" fill="none" stroke="currentColor" stroke-width=".5"/>
  <text font-size="7" letter-spacing="2.4" fill="currentColor">
    <textPath href="#seal">STUDIO NULL · SHANGHAI · EST MMXXI ·</textPath>
  </text>
  <text x="50" y="56" text-anchor="middle" font-size="15" fill="currentColor">SN</text>
</svg>
```

### 页脚

- 顶部 1px 线，四栏；11px；最后一行版权 + 年份
- 不要社交媒体彩色图标；用文字链接

## 7. 动效

| Token | 值 |
|---|---|
| `--dur` | `600ms` |
| `--dur-slow` | `900ms` |
| `--ease` | `cubic-bezier(.22,.61,.36,1)` |

### 编排

- 首屏：eyebrow → 标题 → 饰线 → 正文 → 链接，依次淡入 + 上移 8px，间隔 80ms
- 饰线：`scaleX(0 → 1)`，700ms，单独触发
- 链接 hover：下划线颜色变化，250ms
- 页面内**没有**持续运动；不要浮动、呼吸、视差
- 允许一次滚动触发：标题淡入，仅一次

### 降级

`prefers-reduced-motion: reduce` → 所有位移取消，元素直接显示；饰线不做展开。

## 8. 图像与图标

- 展示页装饰图最多 1 张；静物、建筑、档案照片；暖色调 duotone
- 图片加 1px 细框 + 8px 白边（像装裱），不要圆角、不要阴影
- 没有图片时：用标题、饰线、留白，不要插画
- 展示页图标：如必须，1px 线性、方形端点、16/20；不混填充。应用工具栏按组件规范统一图标库、尺寸和线宽（消息输入区见 §6）；品牌徽记、印章和装饰符号不作为操作图标使用。
- 禁止：3D、渐变、发光、emoji、卷草花纹、金色渐变字

### 聊天背景（书页留白）

保留侧栏 `--surface` 和会话区 `--paper`，不新增底色。用现有书本徽记和双细线丰富留白，装饰不进入正文、表格、导航项和「圆角纸面」输入区。

| 区域 | 规范 |
|---|---|
| 侧栏留白 | 导航与底部工具之间放一枚 `92 × 92px` 双线藏书票，内用已有品牌徽记，不加文字，不重复平铺。使用 `--gold`，浅色不透明度 `22%`、深色 `15%`。仅当侧栏留白高度至少 `140px` 时显示；空间不足直接隐藏，不撑高侧栏。 |
| 正文页边 | 只在正文右侧既有留白加一组上下呼应的 L 形双线角标：外线约 `40px`，内线 `26px`，错开 `5px`，每根 `1px`，颜色 `--line`。右侧留白不足 `96px` 时隐藏。不为装饰缩窄正文或增加横向滚动。 |
| 正文与控件 | 字后保持纯色，不铺纹理、网格、水印或照片。背景不滚动、不播放动效，不承载信息，也不响应点击或截获焦点。用伪元素或 `aria-hidden="true"`、`pointer-events: none` 的装饰层。 |

默认隐藏装饰，确认实际空间足够后分别启用。藏书票判断的是侧栏导航与底部工具之间的空白高度，不是窗口高度；角标判断的是阅读列右缘到主区右缘的净空，不是窗口宽度。比如阅读列上限 `760px` 且两侧等宽时，主区宽度至少 `952px` 才能启用角标；非对称布局按实际右侧空间判断。条件不满足时不预留占位。

预览固定为浅色，用于对照边线、留白和输入框的外观；产品照 §3 使用对应主题色。没有可复用的品牌徽记时不显示藏书票；强制颜色模式隐藏两层装饰。不添加泛黄纸纹、水印、目录点线或罗马编号来弥补留白。

## 9. 文案

- 正式但不古板；短句，名词优先
- 标题 4–12 字；避免感叹号、网络用语
- 英文小标题 2–4 个词，全大写
- 示例：
  - 好：“让想法，落到屏幕上。”
  - 好：“少一点，准一点。”
  - 差：“尊享极致奢华体验，开启非凡之旅！”

## 10. Do / Don't

| Do | Don't |
|---|---|
| 展示页居中对称；应用界面沿用任务布局 | 把聊天正文、表单或侧栏强制居中 |
| 双线框 + 菱形饰线 | 卷草花纹 / 金色渐变 |
| 一个旧金，5% 面积 | 金色铺满按钮和标题 |
| Cormorant 大字 + Inter 正文 | 全站 Cormorant（小字断笔） |
| 一座印章 | 每屏都有印章 |
| 书页角线和藏书票只放在已有留白 | 在正文下面平铺纹理、水印或装饰图 |
| 结构边框直角；输入区、发送按钮用指定圆角；无阴影 | 把输入框做成直角，或把指定圆角扩散到所有卡片、表格 |
| 600–900ms 淡入 | 弹跳、旋转、视差 |

### 如果要收敛（保留风格的降级版）

- 双线框 → 单线框
- 印章 → 可去掉
- 旧金 → 只保留 `--gold-ink` 用于线
- 动效 → 400ms，仅淡入

## 12. 给 AI 的 prompt（按界面类型选一份）

### 聊天应用

```text
按 DESIGN.md 的「书页留白」与「圆角纸面」实现聊天界面。保留项目原技术栈、布局、内容和交互。若能读取 chat-background.html，用它核对外观，不复制预览的切换器、静态文案或禁用输入框。

1. 布局不动：保留侧栏、消息滚动区和输入框位置；输入框与消息列对齐。正文、表格、输入内容左对齐。
2. 使用纯色：主区 #F4EFE4，侧栏和输入框 #FBF7EE，正文 #1C1A17。页面结构保留直角；无阴影、渐变、纸纹、水印、目录化编号或入场动效。
3. 装饰只进留白：侧栏空白高度至少 140px 时放单枚现有徽记藏书票，92px、#9A7B4F、22% 不透明度。正文右侧净空至少 96px 时放一对 #D8D0BF 双细线角标。空间不足各自隐藏，不增加页边距、不挤正文、不拦截点击。
4. 输入区：16px 圆角，1px #B6AA96 单边框；输入层无边框。附件是透明的 44×44px 点击区，发送是 44×44px 正圆，启用用墨色底、禁用用浅暖灰底。回形针和向上箭头同一套线性图标，19px、1.75px 线宽；键盘焦点可见，保留多行输入与附件处理。
5. 验收：宽窄屏检查横向溢出；开关装饰前后对比正文、输入框位置；检查空白禁用、可发送、附件、多行和键盘焦点。
```

### 展示页

```text
按 DESIGN.md 实现 [页面类型]，保留真实内容和项目原技术栈。用象牙纸色 #F4EFE4、墨色 #1C1A17 和少量旧金 #9A7B4F。首屏居中对称，容器最大 1240px，采用双细线框。标题用 Cormorant Garamond / 宋体，正文用 Inter / 中文无衬线；小号金字用 #7A5C34。

结构直角、无阴影、无渐变。正文跳转用下划线链接。菱形饰线、单枚印章和罗马编号只按 §6 使用。窄屏保持细框并重排栏目，键盘焦点可见。若做首屏动效，按 §7 保留 reduced-motion 降级。不要照搬聊天的背景装饰和输入区。
```

## 13. 验收清单

- [ ] 展示页居中对称，双线框完整；应用界面保留原任务布局，不强制对称
- [ ] 结构外框与展示卡片为直角；只有 §6 明确允许的控件使用圆角；无阴影、无渐变
- [ ] 内容跳转用带下划线的链接，发送/提交用按钮；没有把两种动作做成同一种控件
- [ ] 如有消息输入区：外框 `16px` 圆角、单细边，输入层没有第二道边框；附件和发送的图标来自同一套
- [ ] 如有消息输入区：附件和发送均为 `44 × 44px`；能区分空白禁用、可发送、键盘焦点；窄屏及多行输入不重叠
- [ ] 如采用书页留白：正文、表格与输入区仍是纯色；宽屏关闭装饰前后，消息列、输入框和侧栏工具位置一致
- [ ] 侧栏留白不足 `140px` 时无藏书票，正文右侧净空不足 `96px` 时无角标；两者独立判断，强制颜色模式均隐藏
- [ ] 聊天在 `320px`、`390px`、`1024px`、`1440px` 下无页面级横向溢出；侧栏开合、长内容和多行输入不挤压操作区
- [ ] 装饰性旧金最多一处、面积 ≤5%；书页角标用 `--line`，不是第二处金色强调
- [ ] 小字金使用 `--gold-ink`，对比度 ≥4.5:1
- [ ] 中文标题用宋体 500，不是 700
- [ ] 标题 ≤2 行，无孤字
- [ ] 如有展示页印章，≤1 个，旋转 -8°
- [ ] 如有展示页入场动效，600–900ms，无持续运动
- [ ] reduced-motion 下内容完整
- [ ] 如有展示页导航与服务栏目，620px 以下导航不挤、服务单列
- [ ] 没有卷草花纹 / 金色渐变 / emoji
